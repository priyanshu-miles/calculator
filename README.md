# 🧮 Calculator in C

A simple **menu-driven calculator** built using the C programming language. This project performs basic arithmetic operations using **functions**, **switch-case**, and a **while loop**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🚫 Division by zero handling
* 🔁 Repeating menu until the user chooses to exit
* ❌ Invalid choice handling

## 🛠️ Technologies Used

* C Programming Language
* Standard C Library (`stdio.h`)

## 📂 Project Structure

```text
calculator.c
```

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/C-Calculator.git
   ```

2. Open the project folder.

3. Compile the program:

   ```bash
   gcc calculator.c -o calculator
   ```

4. Run the executable:

   **Linux/macOS**

   ```bash
   ./calculator
   ```

   **Windows (MinGW)**

   ```bash
   calculator.exe
   ```
